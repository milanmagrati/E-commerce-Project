## 📞 TROUBLESHOOTING GUIDE

### Issue: Webhook not working
- Check: NCM_WEBHOOK_SETUP.md → Troubleshooting
- Verify: Signature verification
- Check: logs/ncm_webhooks.log

### Issue: Status not updating
- Check: Order has ncm_order_id
- Verify: Webhook is being received
- Test: Manual sync endpoint

### Issue: Alertify not showing
- Check: base.html has Alertify includes
- Verify: JavaScript console for errors
- Try: Hard refresh (Ctrl+Shift+R)

### Issue: SMS not sending
- Check: SMS_ENABLED = True
- Verify: Customer has phone number
- Check: logs/ncm_sms.log

→ Full troubleshooting: [NCM_WEBHOOK_SETUP.md](NCM_WEBHOOK_SETUP.md) Troubleshooting section
