{% comment %} One sortable column header for the WooCommerce orders table. Expects `label` (heading text) and `key` (the ascending sort key, e.g. "date"), plus `sort` and `querystring_nosort` from the view. Clicking toggles between `key` and `-key`; the arrow shows the active direction. Defaults to descending on first click for date/total/id, where "biggest first" is what an operator actually wants. {% endcomment %} {% if sort == key %} {{ label }} {% elif sort == '-'|add:key %} {{ label }} {% else %} {{ label }} {% endif %}
