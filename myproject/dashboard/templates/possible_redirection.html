How Redirection Works
  1. Click "Sync RTV from NCM" to fetch the latest RTV (Return to Vendor) orders from NCM.
  2. All NCM RTV orders appear here. Orders linked to local orders show customer details.
  3. Click the button to open the redirect modal — details are fetched from NCM if no local order exists.
  4. Use "NCM — Redirect Order" to redirect via NCM's redirect API to a new customer/address.
