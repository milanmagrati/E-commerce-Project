{% comment %} The Theme 2 editing chrome: panel, section, field, button, media picker and repeater. Two screens draw it - Setup > Product Page Theme, and the landing-page panel on the product add/edit form - so it lives in one partial they both include. It is a template rather than a stylesheet on purpose. This project runs with DEBUG=False, where WhiteNoise reads the static tree once at start-up: a *new* static path 404s until the server is restarted, which is a trap to walk into every time a screen like this gains a file. A partial has no such path. `product_theme_editor_js.html` is the behaviour that goes with it; the two are a pair and neither is much use alone. One palette throughout, so the two screens cannot drift apart: ink #101828 / #344054 / #475467 / #667085 / #98A2B3, lines #EAECF0 / #D0D5DD, surfaces #fff / #F9FAFB / #FCFCFD, brand #E8590C / #C2410C on #FFF7F2. {% endcomment %}
