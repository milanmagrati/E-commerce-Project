{% comment %} Sentinel Vault device probe. Writes a small `sv_dev` cookie describing the machine, which sentinel/utils.py reads back on the next request. It exists because the user-agent string cannot be trusted about hardware: Chrome for Android's "Request desktop site" sends a verbatim Linux-desktop UA, and iPadOS Safari has claimed to be a Mac since 13. Touch points and the real panel size are not rewritten by either, so they are what actually identifies a phone. Nothing here is a secret — screen size, touch support, time zone — and it is deliberately inline so the sign-in page carries it without depending on collectstatic having run. {% endcomment %}
