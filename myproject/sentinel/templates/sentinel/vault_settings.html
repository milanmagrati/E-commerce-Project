How Sentinel Vault captures

Sign-ins & devices

Hooked into Django's authentication signals, so every entry point is covered — the admin dashboard, the storefront, and anything added later. Each device is fingerprinted from its browser family, OS and network block, deliberately coarse so a browser update doesn't read as a new machine.

Data changes

Model signals snapshot each record before and after it is saved, so the trail records exactly which fields changed and to what. Passwords, tokens and API keys are replaced with •••••••• before anything is written.

Risk scoring

Every action scores 0–100 from its type, the sensitivity of the record and fields touched, whether the device is recognised, and the time of day. The reasons behind a score are stored with the event and shown in its detail panel.
